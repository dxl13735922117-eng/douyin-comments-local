# 浏览器连接与读取故障

先阅读当前浏览器工具提供的 troubleshooting 文档，并遵守其中的恢复顺序。不要检查浏览器控制工具的内部实现或换原始 CDP。

## 能列标签，但读不了正文

标签标题和网址可能来自元数据，不能作为 DOM 正常读取的证据。用同一浏览器、新建的本聊天标签，在用户允许的简单网页上读取一段实际正文；成功后再判断是否为抖音特有问题。

若得到 `Debugger unattached`，或者简单页面的正文和标签截图都超时，记录具体操作及错误，不继续把问题归因于抖音选择器。重复相同调用通常不能修复连接。

按[OpenAI 官方浏览器扩展排障流程](https://learn.chatgpt.com/docs/chrome-extension#troubleshooting)处理：确认站点未被阻止、应用和扩展更新、使用装有扩展的正确配置、扩展侧栏可加载、设置中的浏览器显示 Manage。按已完成步骤继续，不机械地让用户重复所有步骤。

浏览器重启和新聊天均无效后，官方流程包括重启桌面应用，仍失败再通过设置重装扩展，最后用 `/feedback` 附聊天 ID 反馈。重启当前桌面应用会中断聊天，需要用户手动完成。在开发时的一次真实会话中，桌面应用重启后正文读取恢复；这不是对所有环境的保证。

## 具体停止条件

- 站点权限、URL 策略或安全检查拒绝某动作后，说明具体受阻动作；不从另一界面或底层协议实现同一受阻结果。
- 无浏览器控制工具：说明缺少宿主能力。安装这个 skill 本身不会安装或授予 Chrome 控制权限。
- 无法关联父子评论或正文选择器不匹配：保留已有批次，停止该楼的结构化采集并说明范围。
- 登录/验证码：交接给用户，保留待续标签，返回前已读取范围。
- 工具停用或用户接管：暂停页面操作，按工具提示说明情况，不盲目重连。

不要记录 Cookie、令牌、密码或无关标签页内容。排障记录只需要目标站点、调用类型、错误、已完成的修复步骤和数据是否读到。
